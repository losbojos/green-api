# green-api

Веб-чат для MAX через [GREEN-API](https://green-api.com): логин по учётным данным инстанса, поиск контакта по телефону, отправка и получение текстовых сообщений.

Стек: React + TypeScript + Vite.

## Локально

```bash
npm install
npm run dev
```

Сборка и превью: `npm run build` / `npm run preview`.

## GitHub Pages

Деплой при пуше в ветку `deploy` (workflow `.github/workflows/deploy.yml`).

Сайт: https://losbojos.github.io/green-api/
